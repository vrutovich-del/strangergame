# Как выпустить новый скин

Скин добавляется **одним объектом** в файле `src/heroes/<герой>/skins.ts`. Магазин, ящики, карточки героев и бой подхватят его сами.

## Пример: перекраска

```ts
{
  id: 'ice',                       // латиницей, без пробелов, уникально для героя
  heroId: 'smile',
  name: 'Ледяной Смайл',            // как увидят игроки
  price: 79,                        // цена: 29, 79 или 149
  currency: 'gems',                 // 'gems' — кристаллы, 'bling' — блинги (цветовые вариации)
  rarity: 'epic',                   // common / rare / epic / legendary
  cardColor: '#7fd6ff',             // цвет карточки в магазине
  desc: 'Холодный, как мороженое.', // короткое описание
  palette: {                        // перекраска модели (ключи — из SMILEY_PALETTE в model.js)
    skinTop: 0xe8f8ff, skinMid: 0xa8e0ff, skinBottom: 0x5aa8e0,
    limb: 0xa8e0ff, lid: 0xb8e8ff, forehead: 0xd8f4ff,
  },
  shotColor: 0x9fe8ff,              // цвет смайликов-снарядов
  sfxPitch: 1.2,                    // выше или ниже звук выстрела
},
```

Список цветов, которые можно менять, лежит в начале файла модели:
- Смайл — `SMILEY_PALETTE` в `src/heroes/smile/model.js`;
- Бактерия — `PURPLE_GERM_PALETTE` в `src/heroes/bacteria/model.js`.

Цвет записывается как `0xRRGGBB`.

## Детали (шлем, корона, рога…)

Детали дорисовываются кодом в функции `decorate()` в `src/heroes/<герой>/view.ts`. Готовые примеры:
- шлем Космо-Смайла (стеклянный пузырь, воротник, антенна, кепка спрятана);
- корона Вируса-Короля;
- радужные жгутики Радужной Бактерии.

Новую деталь прикрепляйте к узлу `torso`, чтобы она двигалась вместе с героем. Если деталь должна анимироваться отдельно, назовите её и добавьте имя в `joints`.

## Скин из своей модели или текстуры

1. Положите файл модели в `public/assets/heroes/<герой>/<скин>.glb`.
2. В объекте скина укажите `glb: 'assets/heroes/<герой>/<скин>.glb'`.
3. Загрузите модель при старте игры функцией `loadGlb('<герой>', '<скин>', путь)` из `src/render/models.ts`. Она сама масштабирует модель, ставит её на землю и добавляет обводку.

Узлы модели лучше назвать так же, как у основной модели (`torso`, `arm_L`, `eye_L`…). Тогда анимации героя заработают и на новом скине.

## Эксклюзив пропуска

Скин с `exclusive: 'pass'` нельзя купить. Его выдаёт финальная награда премиум-линии пропуска (`passRewards` в `src/meta/economy.ts`), поменяйте её там.

## Проверка

1. `npm run dev` → Полигон → «любой герой и скин» → выберите новый скин и посмотрите в бою.
2. Магазин → раздел «Скины» → проверьте картинку и цену.
3. `npm test`.
4. Добавьте запись в `src/changelog.ts` и выпустите версию (см. README).

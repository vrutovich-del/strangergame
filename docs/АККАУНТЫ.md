# Аккаунты: вход и регистрация

В игре есть вход по **логину и паролю**. Прогресс (трофеи, герои, скины, валюта) сохраняется в облаке, и на другом телефоне или компьютере достаточно войти в тот же аккаунт.

Чтобы это заработало, нужен бесплатный проект **Firebase** (это сервис Google). Его настраивают один раз, минут за 10. Пока он не настроен, игра работает как раньше: прогресс хранится только на устройстве, а кнопок входа нет.

> Почта игрокам не нужна. Логин превращается в «ненастоящий» адрес вида `u…@players.igra-strannostey.game`, никакие письма никуда не уходят. Пароль хранит Firebase в зашифрованном виде — в игре и в базе его нет.

## 1. Создать проект

1. Откройте [console.firebase.google.com](https://console.firebase.google.com) и войдите в аккаунт Google (лучше взрослому).
2. **Create a project** (Создать проект) → имя, например `igra-strannostey` → Google Analytics можно выключить → **Create project**.

## 2. Включить вход по паролю

1. Слева: **Build → Authentication** → **Get started**.
2. Вкладка **Sign-in method** → **Email/Password** → включить первый переключатель (**Enable**) → **Save**.

## 3. Создать базу для сохранений

1. Слева: **Build → Realtime Database** → **Create Database**.
2. Место хранения — любое (например, `europe-west1`) → **Start in locked mode** → **Enable**.
3. Вкладка **Rules** (Правила) → удалите всё и вставьте:

```json
{
  "rules": {
    "saves": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid",
        ".validate": "newData.hasChildren(['savedAt', 'data']) && newData.child('data').isString() && newData.child('data').val().length < 200000"
      }
    }
  }
}
```

4. **Publish** (Опубликовать). Теперь каждый игрок может читать и менять только своё сохранение.
5. Вверху страницы базы есть адрес вида `https://igra-strannostey-default-rtdb.europe-west1.firebasedatabase.app` — это **databaseURL**, он понадобится дальше.

## 4. Получить ключ

1. Слева вверху: ⚙️ → **Project settings** → вкладка **General**.
2. Внизу, в разделе **Your apps**, нажмите значок **`</>`** (Web) → имя, например `game` → **Register app**.
3. Появится код с `firebaseConfig`. Оттуда нужны две строчки: **apiKey** и **databaseURL**.

## 5. Вписать в игру

Откройте `src/config.ts` и заполните:

```ts
export const CLOUD = {
  apiKey: 'AIza…ваш ключ…',
  databaseURL: 'https://igra-strannostey-default-rtdb.europe-west1.firebasedatabase.app',
  emailDomain: 'players.igra-strannostey.game',
};
```

`apiKey` — не секрет: он есть в любой веб-игре на Firebase и только говорит, какой это проект. Защищают данные правила базы из шага 3.

Потом выпустите новую версию, как обычно (`git add -A`, `git commit`, `git push`). Через пару минут в игре появятся кнопки **«Создать аккаунт»** и **«Войти»**: при первом запуске и в **Профиле → Аккаунт**.

## Как это работает для игрока

- **Создать аккаунт:** логин (3–14 букв или цифр, можно по-русски) и пароль (от 6 символов). Текущий прогресс с этого устройства сразу уходит в облако.
- **Войти на другом устройстве:** тот же логин и пароль — прогресс подтянется. Если и там уже был свой прогресс, игра спросит, какой оставить.
- После каждого боя и покупки прогресс сохраняется в облако сам (через пару секунд). Без интернета игра работает как обычно и досохранит, когда связь появится.
- **Выйти из аккаунта** — в Профиле. Прогресс на устройстве остаётся.
- Пароль восстановить нельзя (почты нет), поэтому его надо запомнить. На всякий случай остаётся **код переноса** в Настройках.

## Если что-то не работает

- «Аккаунты ещё не подключены» — пустые `apiKey` или `databaseURL` в `src/config.ts`.
- «Что-то пошло не так» при регистрации — проверьте, что в шаге 2 включён **Email/Password**.
- Вход работает, но прогресс не сохраняется — проверьте правила базы (шаг 3) и что `databaseURL` скопирован целиком.
- Бесплатного тарифа Firebase (Spark) для такой игры хватает с большим запасом.

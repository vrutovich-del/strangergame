# Игра странностей

Командный аркадный шутер с видом сверху для браузера. Работает на телефоне, планшете и компьютере.
Можно играть одному с роботами или с друзьями по коду комнаты.

## ▶️ Играть

**https://vrutovich-del.github.io/strangergame/**

![QR-код ссылки на игру](docs/qr.png)

Наведи камеру телефона на QR-код, чтобы открыть игру.

- **Android (Chrome):** откройте ссылку и нажмите «Установить приложение» (или ⋮ → «Добавить на главный экран»). Игра откроется на весь экран.
- **iPhone (Safari):** откройте ссылку, нажмите «Поделиться» ⬆️ → «На экран „Домой“» и запускайте игру с иконки. Только так она откроется на весь экран.
- Играть нужно, держа телефон **боком**.

## Что внутри

- Герои: **Смайл** (стрелок, супер — три летающих смайла), **Бактерия** (дробовик, супер — заражение на 5 секунд) и **Лев** (когти вблизи, супер — прыжок на врага через стены и град ударов).
- В начале открыт только Смайл. Остальных героев дают **Старр-дропы** за победы, ящики и Дорога трофеев. У героев и скинов есть **редкость**.
- Боты — **роботы**: Бластер, Танк и Снайпер.
- Режимы: Захват кристаллов 3×3, Выживание, Нокаут до 2 побед и Тренировочный полигон.
- Игра с друзьями: кнопка «С ДРУЗЬЯМИ» сразу создаёт комнату с кодом из 5 символов; друг вводит код — и он в команде. До 3 игроков против роботов.
- **Аккаунты:** вход по логину и паролю, прогресс в облаке и на любом устройстве (нужно один раз настроить — [docs/АККАУНТЫ.md](docs/АККАУНТЫ.md)).
- Магазин, ящики, скины, Дорога трофеев, Боевой пропуск, задания и награды за вход.
- **Никаких реальных платежей.** Всё покупается за игровую валюту.

## Как запустить на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет команда (обычно http://localhost:5173). Чтобы зайти с телефона в той же Wi‑Fi сети, используйте адрес «Network».

Другие команды:

```bash
npm test          # автотесты
npm run build     # сборка в папку dist
npm run icons     # перерисовать иконки
npm run qr        # перерисовать QR-код docs/qr.png
```

## Как выпустить новую версию

1. Поменяйте номер версии в `src/config.ts` (`GAME_VERSION`) и в `package.json`.
2. Добавьте запись в начало `src/changelog.ts`. Игроки увидят её в окне «Что нового».
3. Отправьте изменения на GitHub:
   ```bash
   git add -A
   git commit -m "Версия 1.1.0: …"
   git push
   ```
4. GitHub Actions сам прогонит тесты, соберёт игру и опубликует её. Через 1–2 минуты ссылка покажет новую версию.

Если сборка упала, откройте вкладку **Actions** в репозитории и посмотрите, на каком шаге ошибка.

### Первая настройка GitHub (один раз)

1. Зайдите в аккаунт на [github.com](https://github.com) (или заведите новый).
2. Создайте репозиторий и отправьте в него проект (`git push`).
3. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
4. Перезапустите сборку: вкладка **Actions** → последний запуск → **Re-run all jobs**. Или просто сделайте новый `git push`.

## Устройство проекта

```
src/
  core/      цикл кадров, ввод (тач/клавиатура/мышь/геймпад), сетка и столкновения, события
  sim/       симуляция боя 30 тиков в секунду (без графики)
  render/    Three.js: сцена, модели, обводка, частицы, анимации
  heroes/    по папке на героя: config.ts, index.ts (атака и супер), view.ts (вид), skins.ts, model.js
  bots/      роботы и их ИИ
  modes/     gemgrab/, showdown/, knockout/, training/
  maps/      карты в ASCII
  meta/      валюты, прокачка, ящики, пропуск, задания, сохранение
  net/       комнаты и сетевая игра (PeerJS), аккаунты и облачное сохранение (cloud.ts)
  ui/        экраны меню, HUD боя
  audio/     звуки и музыка, сгенерированные кодом
public/      иконки, манифест, модели .glb
docs/        документация
```
